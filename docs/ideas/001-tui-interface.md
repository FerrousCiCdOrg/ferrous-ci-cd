# アイデア: 軽量 TUI をプロダクトの差別化ポイントに

- **記録日**: 2026-07-09
- **ステータス**: アイデア（ロードマップ未確定）

## 概要

Ferrous CI/CD は Rust で書かれている。これはそのまま、**軽量で見やすい Text User Interface (TUI)** として提供しやすいという強みになる。

パイプラインの実行や、その進捗・ステータス表示を、軽量で見やすい TUI として画面に出せるのが良いのではないか。他の CI/CD ツールが真似できていない、独自の UI になりうる。

## なぜ良いか

- Rust の TUI エコシステム（`ratatui` + `crossterm` など）は成熟しており、高速・低オーバーヘッドなターミナル UI を自然に作れる。
- パイプラインの並列実行状況、ログのストリーミング、ステージ／ジョブごとの進捗を「一画面」で見せる用途にぴったり。
- 「ターミナルでCI/CDの実行状況を美しく見られる」という体験は、既存ツールが取っていない差別化の角度。

## 今後の活かし方

- UX や機能を設計するときに「これは TUI で表現できるか？」を評価軸のひとつにする。
- TUI（パイプライン実行＋ステータス可視化）を、後回しの機能ではなく**目玉候補**として扱う。
